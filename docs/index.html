What's included

Research12-filter stock screener + earnings calendar
TechnicalsDaily + intraday charts, RSI, MACD, Bollinger
OptionsP/L calculator, Greeks, IV chain
CryptoBTC, ETH, SOL charts + screener
Deep DiveFundamentals, ratings, financials
Paper Trading$100k virtual portfolio
SentimentBullish/bearish news scoring
PortfolioHoldings, sectors, correlation
ReportsExport PDF summaries
BacktestSMA & RSI strategy testing
Honest pitch: This is a portfolio project — not a Bloomberg replacement, not financial advice. Market data comes from Yahoo Finance. News from public RSS feeds. Your portfolio and paper trades stay on your machine.

Install in 30 seconds

git clone https://github.com/FiltoreUNSC/finance-hub.git
cd finance-hub && ./install.sh && ./run.sh
→ opens at localhost:8501

Python 3.11+ required. Not financial advice.
