# Screenshot Checklist for GitHub / Social

Record these from a running Finance Hub (`./run.sh`). Use macOS Cmd+Shift+4 or fullscreen screenshots.

## Required (5 shots)

1. **Hero** — Full app with market tape visible at top + sidebar watchlist
2. **Technicals** — Candlestick chart with RSI/MACD (pick NVDA or AAPL)
3. **Options Greeks** — Delta/Gamma/Theta metrics + payoff chart
4. **Paper Trading** — Open positions with P/L showing
5. **Sentiment** — Pie chart with bullish/bearish breakdown

## Nice to have (3 shots)

6. **Screener** — Filter results table with multiple matches
7. **Crypto** — BTC chart with indicators
8. **PDF Reports** — Generate button + download ready state

## Tips

- Use dark mode (default) — already branded
- Pick tickers people recognize: AAPL, NVDA, BTC, SPY
- Crop to 1280×800 or 16:9 for README hero image
- Add 1 cover image in Canva: dark bg, green accent, "Finance Hub" title
